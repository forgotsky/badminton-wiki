# 羽毛球七维评估

> 🔗 [[羽毛球主页]] · [[羽毛球技术体系]] · [[羽毛球训练课实操手册]]

> 教练工具：把学员拆成 7 个维度分别打分（用中羽 1~6 级当刻度），找出短板。具体怎么练，见「羽毛球训练课实操手册」。来源：肖杰羽毛球教学 45 集 + BWF 教练手册 + 中羽评级。

## 怎么用（三步）

1. **评估**：给学员 7 个维度各打一个 1~6 级的分，画成雷达图。
2. **找短板**：看哪几维分最低。
3. **练**：去「羽毛球训练课实操手册」翻到对应维度的章节照练。

## 怎么打分（测评方法，别凭感觉）

| 维度 | 怎么测 |
|---|---|
| ① 发接发 | 发 20 个球（高远球/网前小球各 10），数进有效区个数；接发球看判断和启动 |
| ② 技术 | 定点多球，每个技术打 10~20 个，看落点、质量、动作 |
| ③ 步法 | 教练手势指挥跑六点，看到位率、回中、有没有启动步 |
| ④ 战术 | 实战看球路选择：会不会调动、会不会找弱点、被动会不会处理 |
| ⑤ 体能 | 打满一局看掉不掉速；四角跑计时 |
| ⑥ 心理 | 关键分/落后局的表现；失误后的下一拍 |
| ⑦ 实战 | 打几场计分赛，看失误率、稳定性、能不能执行打法 |

打分原则：**看的是「实战中能不能稳定做出来」，不是「会不会做这个动作」**。定点能做、实战做不出来的，说明还没到那级。

## 七维 · 1~6 级判断标准

### ① 发接发（前 3 拍定胜负）

| 级 | 判断标准 |
|---|---|
| 1 | 发球能过网但质量差、失误多；接发球基本靠反应 |
| 2 | 正手发高远球能到底线；发网前小球基本能过；接发球能判断 |
| 3 | 发球稳定（高远球到底线、网前贴网）；接发球能移动到位 |
| 4 | 发球有变化（高/低、内角/外角），动作一致性好；接发球能抢前点 |
| 5 | 发球精准多变、有欺骗性；接发球能抢攻、直接得分 |
| 6 | 发接发完全掌控，能靠前 3 拍定节奏、定胜负 |

### ② 技术（手法）

| 级 | 判断标准 |
|---|---|
| 1 | 会握拍发球，高远球打不到底线 |
| 2 | 高远球能到底线；会挑/放/推/勾/吊但失误高；反手后场不会 |
| 3 | 实战中稳定完成高远球（3 级标志）；主动吊杀搓都能做，质量一般 |
| 4 | 四方球四点稳定；高吊杀搓推勾有质量；反手能过渡 |
| 5 | 全技术解锁且质量高；反手充分发力到后场；手法隐蔽一致 |
| 6 | 技术细腻稳定、失误极少，接近专业 |

### ③ 步法

| 级 | 判断标准 |
|---|---|
| 1 | 移动慢、重心不稳，常打空打偏 |
| 2 | 有零星步法但不连贯，容易被吊死，回中意识差 |
| 3 | 掌握踮步/并步/弓箭步/交叉步；能跑全场六点但不流畅 |
| 4 | 六点步法连贯，启动回动到位，重心稳 |
| 5 | 步法流畅、启动快回动快，能抢高点，全场无死角 |
| 6 | 步法精简高效，几乎无多余步伐，防守范围大 |

### ④ 战术

| 级 | 判断标准 |
|---|---|
| 1 | 只会打直线，没有球路意识 |
| 2 | 能打简单拉吊，被动不会处理 |
| 3 | 会拉吊突击/压底线等基本套路，能调动对手 |
| 4 | 能根据对手弱点选球路，攻防有章法 |
| 5 | 战术多变、能临场调整，单双打套路熟练 |
| 6 | 球路精准、节奏控制强，牵着对手走 |

### ⑤ 体能

| 级 | 判断标准 |
|---|---|
| 1 | 打一局就喘，移动范围小 |
| 2 | 能打完整局，后半段明显掉速 |
| 3 | 能打 2~3 局，速度力量一般 |
| 4 | 速度力量耐力均衡，能打满一场 |
| 5 | 速度突出、速度耐力强，整场不掉速 |
| 6 | 专业级体能，高强度对抗游刃有余 |

### ⑥ 心理

| 级 | 判断标准 |
|---|---|
| 1 | 一失误就慌，落后就放弃 |
| 2 | 落后会急，关键分手软 |
| 3 | 基本稳定，关键分/被追分时心态波动 |
| 4 | 能顶住压力，关键分基本正常发挥 |
| 5 | 心态稳抗压强，落后能翻盘 |
| 6 | 大心脏，越关键越稳，情绪完全掌控 |

### ⑦ 实战/稳定性

| 级 | 判断标准 |
|---|---|
| 1 | 接不到、打不中，还不能对打 |
| 2 | 能对拉几拍，失误多、打不满一局 |
| 3 | 能打完比赛，失误偏高、容易被针对 |
| 4 | 失误少、稳定发挥，能打有质量的比赛 |
| 5 | 稳定性高、经验丰富，能赢同级别对手 |
| 6 | 稳定 + 高竞技水平，业余顶尖 |

## 雷达图样例（一个学员怎么评）

学员小张（学球 3 个月）：

| 维度 | 级 | 说明 |
|---|---|---|
| ① 发接发 | 3 | 高远球能到底线、网前小球还行，但变化少 |
| ② 技术 | 3 | 高远球稳定，会吊杀搓，质量一般 |
| ③ 步法 | 2 | 能跑六点但不流畅，回中慢、没启动步 |
| ④ 战术 | 1 | 只会打直线 |
| ⑤ 体能 | 3 | 一般 |
| ⑥ 心理 | 2 | 落后就慌 |
| ⑦ 实战 | 2 | 对打失误多 |

→ **短板：步法、战术、心理、实战**。排课重点：先补步法 + 战术，技术先放一放。

## 成长口诀

1~3 级纠动作、4~5 级练脚步、6 级抠细节。
